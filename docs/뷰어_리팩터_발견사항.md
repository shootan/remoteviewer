Created: 2026-08-27 · 기준 커밋: `e346ff7` (줄 번호는 이 커밋의 `native_video_client_main.cpp` 기준)

## 규칙 (사용자 결정 2026-08-27)

1. 뷰어 분할 리팩터(Phase 0~3)를 진행하며 코드를 읽다가 **잘못 구현된 곳·고도화가 필요한 곳·부채**를 발견하면 **여기에 기록만** 한다. 리팩터 중에는 고치지 않는다(행동 보존 원칙, 회귀 원인 분리).
2. 기록 시점은 **발견 즉시**. 해당 커밋의 `history.md` 항목에 "발견 → F-NN" 한 줄을 남기고 이 표에 행을 추가한다(문서는 main에서만 수정).
3. 리팩터 완료(Phase 3 + 실기 통과) 후 이 표에서 골라 **별도 커밋/사이클**로 처리한다. 동작이 바뀌는 항목은 뷰어 e2e + 실기 게이트.
4. 리팩터 자체가 구조적으로 해소하는 항목(예: F-08 통계 블록 복제)은 "처리 시점" 열에 해당 Phase를 적고, 완료되면 상태를 [x]로.

분류: **버그**(결과가 틀림) · **불일치**(경로 간 다른 구현) · **dead**(미사용 코드/상태) · **스레드**(소유권/친화 smell) · **고도화**(기능/성능 개선) · **부채**(HANDOFF/구현계획에 이미 있는 항목)
