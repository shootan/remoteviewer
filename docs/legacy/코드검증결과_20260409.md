# 구현계획 vs 코드 검증 결과
검증일: 2026-04-09

## 검증 요약

구현계획.md의 모든 체크된 항목(코드 작업)을 실제 코드베이스와 대조 검증했다.
**체크된 코드 항목은 전부 구현이 확인되었으며, 계획과 불일치하는 코드 결함은 발견되지 않았다.**

미완료(체크 해제) 항목은 전부 **수동 검증/런타임 테스트** 항목이며, 코드 작업이 아닌 잔여 확인 작업이다.

### M0. 측정 기준 고정 - PASS
- `automation/verify_native_video_runtime.ps1`: 존재, 압축비 지표 포함

### M1. Host 전처리 가속 - PASS
- `resize_bgra_bilinear`: 고정소수점 bilinear 보간으로 구현 (`native_video_host_main.cpp:1548`)
- GPU 스케일링: `GpuBgraScaler` D3D11 비디오 프로세서 경로 구현 (`native_video_host_main.cpp:1591`), CPU fallback 포함

### M2. Client 표시 경로 가속 - PASS

### M2.5. Host 인코더 큐/제출 병목 추적 - PASS
- 6분할 타임스탬프: capture → queuePush → queuePop → encBegin → encEnd → send 전부 구현
- `HOST_BOTTLENECK_STAGE`: 9개 후보 (queue_wait, queue_to_encode, pre_encode_prep, scale, bgra_to_nv12, encoder, queue_to_send, send_io, send_interval_jitter) 구현
- `encApiPathCode`: AMF=1, NVENC=2, QSV=3, MFT=4, CLSID=5, unknown=6 분류 구현
- send 분해: `sendHeaderUs`, `sendPayloadUs`, `sendChunkCount`, `sendChunkMaxUs`, `sendIntervalUs`, `sendIntervalErrUs` 전부 확인
- `queueWaitReason`: 0=정상, 1=타임아웃, 2=no-work 분류 구현
- `REMOTE60_NATIVE_H264_ASYNC_POLL_MAX`/`SLEEP_US`: `mf_h264_codec.cpp:1554-1555` 확인

### M3. Adaptive 정책 - PASS

## 미완료(미체크) 잔여 항목

아래 항목은 전부 **수동 검증/런타임 테스트**이며, 코드 구현은 이미 완료 상태이다.

### M3.5 검증
- [ ] M3.5 background 입력 주입 1차 수동 검증 (Notepad 클릭/드래그/키입력, OS 마우스 비이동, occluded 입력)

### Android 검증
- [ ] Android desktop-mode valid capture source verify (`desktop` path에서 `GetShellWindow()` fallback 없는 환경 재검증)
- [ ] Android long-run repeat verify (`targets → viewer → back` 반복 10회 이상 soak)
- [ ] Android client-instance exclude automation (`REMOTE60_NATIVE_WINDOWLIST_EXCLUDE_PIDS`를 current emulator instance와 자동 동기화)
- [ ] Android Phase F 착수 Gate 검증 (`full-frame video`, `window select`, `background/foreground resume` 실기기 재확인)
- [ ] Android Phase F tap/drag runtime verify (`Desktop Mode`, selected-window mode 실기기 확인)
- [ ] Android Phase F soft keyboard runtime verify (`committed text`, backspace/enter, control bar discoverability)

## 결론

- **코드 수정 필요 사항: 없음** - 계획 대비 구현 누락이나 불일치가 발견되지 않았다.
- **잔여 작업**: 위 7건의 수동 검증/런타임 테스트만 남아있다.
- 이 중 `Android client-instance exclude automation`은 검증이 아닌 자동화 기능이므로, 필요 시 별도 코드 작업으로 분류 가능하다.
