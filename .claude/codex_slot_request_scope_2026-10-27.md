## 선택 2 — 같은 파일을 남기는 독점 핸들 방식

파일은 같은 경로에 남겨 두고, 각 참여 runner가 OS의 독점 FileStream 핸들을 잡는 동안만 측정 슬롯을 소유한다. 시험/상한/오류 종료 때 핸들을 닫고 **파일은 삭제하지 않는다**. 프로세스 종료 시 핸들도 회수되는 방식이다.

이 경우 기존 existence-only reader를 그대로 두면 영구 대기가 되므로, 검증용 한 창구가 모든 현재 참여자의 관련 runner를 한 번에 맞춘다. 기존 소유 시험의 정상 종료/바깥 파일 보존→측정 run 사이 pause/전환 확인→동일 canonical 파일의 독점 획득/해제 확인→재개 순서로 한다. 새 독립 슬롯 파일을 몰래 병행하지 않는다. 현재 사용자 Host를 종료하거나 오래된 파일을 지울 필요는 없다.
